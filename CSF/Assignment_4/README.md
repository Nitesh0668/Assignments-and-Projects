# Assignment 4 - Software Development Workflow Project

# Project Overview
This project show essential usage of modern software development workflows.
It includes the use of **Visual Studio Code**, **Git**, and **GitHub**.

Purpose:

- Working with development environments
- Using Git version control systems. 
- Managing source code repositories on the GitHub
- Creating documentation

---

## Installation

1. Clone repository:
   git clone https://github.com/Nitesh0668/Assignments-and-Projects.git

2. Then nevigate here:
   cd CSF/Assignment_4

3. Then run the python file:
   python main.py
